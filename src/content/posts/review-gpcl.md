本文是对 GPCL 项目的锐评。

如果你感觉不适，请离开这里。

首先，我们打开 GPCL 项目的 GitHub 仓库首页。

一进来就看笑了，`GoodPlanCraftLaunCher` 是什么东西？“好计划启动器”？

提醒一下，PCL 全称叫 `Plain Craft Launcher`。

接下来，我们看看项目的 README。

'轻量'

'将启动器自身的资源占用控制在极低水平'

Electron 写的项目你给我谈轻量，占用低？？？

Chrome 可是吃内存大户，轻量到哪里去了？

'Java 自动补全'

`Java 自动补全` 是哪里来的说法？不应该叫 `Java 下载 / Java 运行环境补全` 吗？

然后就是 Releases 的命名问题。

这 Releases 都是什么逆天名字啊！

我还去看了一下开发者的 "Wiki" 页面（其实是他自己的 Wiki）

这一堆奖项有什么含金量？
